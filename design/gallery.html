Тёплая бумага

Набор токенов и компонентов для справочников, отчётов и вики. Сделан на базе оформления memory (карточки): тёплая бумага, спокойный текст, читаемые сочетания клавиш.

Цвет

Меняй только значения токенов — компоненты подхватят. Тёмная тема — те же имена.

--paperфон страницы
--surfaceкарточка
--softподложка
--inkтекст
--mutedвторичный
--lineграницы
--keyсочетания
--warnвыноски
--okуспех
Правило: компонент не задаёт цвет напрямую — только var(--token). Тогда смена темы бесплатна.

Сочетания клавиш

Ключевой компонент справочника. Моноширинный, тёплый, читаемый в обеих темах.

Alt+Tab Super+← Ctrl+Alt+t Shift+PgUp

В строке: переключение — Alt+Tab, терминал — Ctrl+Alt+t.

Инлайн-код: gsettings get org.cinnamon.desktop.keybindings.wm close

Как подключить в новом проекте

ШагЧто сделать
1Скопируй папку design/ в проект.
2В <head> добавь два <link>: сначала tokens.css, потом base.css.
3Поставь на <html> атрибут data-theme="light" (или dark). Без атрибута тема следует системной.
4Разметка: .wrap → .hero → .sec с h2[data-n].
5Свои цвета не хардкодь — добавляй токен в tokens.css для обеих тем.
Переключатель темы — три строки JS из hotkeys.html: меняет data-theme на <html>.
