Окна и раскладка

Как переключаться между окнами, делить экран пополам и раскладывать всё по рабочим столам.

Окна: переключение между терминалом и редактором главное

Пишешь код в терминале → смотришь результат в редакторе → возвращаешься. Одна рука, без мыши.

ДействиеСочетаниеПримечание
Переключение окон (Alt-Tab)Alt+TabОтпусти сразу — предыдущее окно. Удерживай и веди Tab для перебора.
В обратном порядкеShift+Alt+Tab
Только окна текущего столаCtrl+Alt+TabНе трогает панели и апплеты.
Свернуть окноSuper+h
Развернуть / вернуть размерAlt+F10 / Alt+F5Вернуть размер также Super+↓.
Закрыть окноAlt+F4

Разложить терминал и редактор на пол-экрана разметка

Не переключайся между окнами — поставь их рядом. Взгляд перескакивает сам, фокус наводишь клавишей.

ДействиеСочетаниеПримечание
Причаливание (tile) и размеры
Слева / справа — половина экранаSuper+← / Super+→То же в muffin (оконный менеджер).
Развернуть / восстановитьSuper+↑ / Super+↓Super+↓ = unmaximize.
Скрыть все окна (рабочий стол)Super+dПовтор — вернуть окна.
Окно на соседний мониторSuper+Shift+←/→/↑/↓
Меню окна / переместить / размерAlt+Space / Alt+F7 / Alt+F8Стрелки двигают, Enter отпускает.

Виртуальные рабочие столы workspaces

Терминал на одном столе, редактор на другом — отдельное пространство под каждый контекст.

ДействиеСочетаниеПримечание
Стол влево / вправоCtrl+Alt+← / Ctrl+Alt+→
Стол вверх / внизCtrl+Alt+↑ / Ctrl+Alt+↓Нет стола «вниз» — Cinnamon создаст его.
На 1-й / последний столSuper+Home / Super+EndПереключение на 2–12 пустое по умолчанию.
Перенести окно на соседний столCtrl+Shift+Alt+←/→/↑/↓Стол и окно одним аккордом.
Перенести окно на 1-й / последнийSuper+Shift+Home / Super+Shift+End
